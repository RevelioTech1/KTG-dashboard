## 📁 Обзор загруженных файлов

### 1. **EVA_Final_08.xlsx** - Система оценки и бонусов
**Назначение**: Комплексная система оценки эффективности работы торговых представителей и расчета бонусов

**Структура**:
- **Лист 1: "Russia_Bonus KPIs"** (187 записей, 49 колонок)
  - Данные по сотрудникам с детальными KPI
  - Информация о территориях и регионах
  - Расчет бонусов и штрафов
  
- **Лист 2: "Rating 08"** (150 записей, 36 колонок)
  - Рейтинги по трем категориям должностей:
    - TSM (Territory Sales Manager) - Территориальный менеджер по продажам
    - BDM (Business Development Manager) - Менеджер по развитию бизнеса
    - RKAM (Regional Key Account Manager) - Региональный менеджер по ключевым клиентам

**Ключевые метрики**:
- `Summary Score` - Итоговый балл
- `Call Rate` - Частота визитов/звонков
- `Route Coverage` - Покрытие маршрута
- `Must Set POSM` - Обязательная установка POSM (Point of Sale Materials - материалы в точках продаж)
- `Must Set SKU Contract` - Выполнение контрактных обязательств по SKU (100%)
- `Must Set SKU Not Contract` - SKU вне контракта (70%)
- `Must Set SKU TTL BY TARGET` - Общая выкладка SKU по целям
- `Actual matching Distr/HS` - Фактическое соответствие дистрибуции
- `POS with Mistakes` - Ошибки в точках продаж (целевой показатель 5%)
- `Final KPI Score` - Финальный балл KPI
- `Incentive Rate` - Ставка премирования
- `Check Tour Penalty` - Штраф за нарушение маршрута
- `Final Incentive Rate` - Итоговая ставка премирования

**Система рейтингов**:
- Шкала оценки от 80 до 200+ баллов
- Система премирования:
  - 2.5% за каждые 10 баллов (для TSM)
  - 2.0% за каждые 10 баллов (для других ролей)
- Прогрессивная шкала премий от 5% до 40%

**Назначение**: Планирование и отслеживание рабочих активностей сотрудников на месяц

**Структура**:
- **Лист 1: "СА June'26"** (185 записей, 64 колонки)
  - Календарь на месяц (30+ дней)
  - Информация о сотрудниках: BDM, Territory, Region, Position
  - Столбцы для каждого дня месяца с двумя полями:
    - `СА` - Тип активности
    - `Time` - Время
  - Система согласований: "Согласовано с BUM" (Business Unit Manager)
  
- **Лист 2: "Sheet2"** - Справочник типов активностей
  - ЦИ - Центральный инцидент
  - ДТП - Дорожно-транспортное происшествие
  - Получение POSM
  - Дорога в/из командировки

  - Sales Day

**Маркеры календаря**:

## 🎯 Цель и суть данных

### Бизнес-процесс
Данные отражают **систему управления продажами FMCG/Retail компании** в России:

1. **Планирование** (CA файл): 
   - Распределение рабочего времени торговых представителей
   - Координация визитов и активностей
   - Контроль использования времени

2. **Выполнение**: 
   - Полевая работа торговых представителей
   - Визиты в точки продаж
   - Выполнение стандартов выкладки и POSM

3. **Оценка** (EVA файл):
   - Измерение результатов по KPI
   - Расчет рейтингов и сравнение с целями
   - Определение размера премий и бонусов

### Основные заинтересованные стороны
- **Торговые представители** (TSM) - полевые сотрудники
- **BDM** - руководители территорий
- **RKAM** - менеджеры ключевых клиентов
- **BUM** - руководители бизнес-юнитов
- **Региональные и корпоративные менеджеры** - принимают стратегические решения

## 🔧 Технические требования

### Рекомендуемый стек технологий:
- **Frontend**: React + TypeScript
- **Visualization**: 
  - D3.js (кастомные визуализации)
  - Recharts / Apache ECharts (стандартные графики)
  - Plotly (интерактивность)
- **UI Framework**: Ant Design / Material-UI / Tailwind + shadcn/ui
- **Backend**: Node.js (Next.js) или Python (FastAPI)
- **Database**: PostgreSQL для хранения исторических данных
- **BI Integration**: Power BI / Tableau (опционально)

### Структура данных для дашборда:

**Основные таблицы**:
```sql
-- Справочники
dim_employees (id, name, position, bdm_id, territory_id)
dim_territories (id, territory_code, region, area)
dim_dates (date, year, month, week, is_weekend, is_holiday)

-- Факты
fact_kpi (
  date, employee_id, territory_id,
  summary_score, call_rate, route_coverage,
  posm_compliance, sku_contract_pct, sku_noncontract_pct,
  final_kpi_score, incentive_rate, tour_penalty,
  final_incentive_rate, rating_position
)

fact_activities (
  date, employee_id, 
  activity_type, hours_planned, hours_actual,
  approval_status, approved_by, approved_date
)
```

### ETL процесс:
1. **Extract**: Загрузка Excel файлов (еженедельно/ежемесячно)
2. **Transform**: 
   - Очистка заголовков
   - Нормализация дат
   - Расчет производных метрик
   - Валидация данных
3. **Load**: Загрузка в БД с версионированием

## 📋 Метрики для мониторинга (KPIs дашборда)

### Группа 1: Производительность продаж
- `Average Final KPI Score` - средний финальный балл
- `% of Employees Above Target` - процент превысивших цель
- `Call Rate Achievement %` - выполнение плана визитов
- `Route Coverage %` - покрытие маршрута

### Группа 2: Compliance (Соответствие стандартам)
- `POSM Compliance Rate` - выполнение стандартов POSM
- `SKU Contract Compliance` - выполнение контрактных SKU (цель 100%)
- `SKU Non-Contract Compliance` - выполнение неконтрактных SKU (цель 70%)
- `Error Rate in POS` - уровень ошибок в точках (цель <5%)

### Группа 3: Финансы
- `Total Incentive Payout` - общая сумма премий
- `Average Incentive Rate` - средняя ставка премирования
- `Incentive Budget Utilization %` - использование бюджета
- `Cost per Point (KPI)` - стоимость балла

### Группа 4: Операционная эффективность
- `Activity Completion Rate` - выполнение плановых активностей
- `Approval Cycle Time` - время согласования
- `Non-Productive Time %` - непродуктивное время
- `Territory Coverage Index` - индекс покрытия территорий

### Группа 5: Качество данных
- `Data Completeness %` - полнота данных
- `Update Frequency` - частота обновления
- `Data Age (days)` - возраст данных
