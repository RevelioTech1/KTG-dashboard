# 📊 Анализ данных для управленческого дашборда

Проект содержит комплексный анализ данных торговой команды для разработки системы управленческих дашбордов.

## 📁 Исходные данные

Проанализированы 2 Excel файла:

1. **EVA_Final_08.xlsx** - Система оценки эффективности и бонусов
   - 187 сотрудников
   - 49 метрик KPI
   - Рейтинги TSM, BDM, RKAM
   
2. **CA_Sep_26.xlsx** - Календарь планирования активностей
   - 185 записей
   - Месячный календарь
   - Система согласований

## 📚 Документация

### Основные документы:
- **[EXECUTIVE_SUMMARY.md](./EXECUTIVE_SUMMARY.md)** - Краткое резюме с визуальными примерами
- **[ANALYSIS_REPORT.md](./ANALYSIS_REPORT.md)** - Полный детальный отчет анализа

### Технические файлы:
- `data_analysis_summary.json` - Структурированное резюме
- `analysis_eva.json` - Детальный анализ EVA файла
- `analysis_ca.json` - Детальный анализ CA файла

## 🎯 Основные выводы

### Суть данных:
Интегрированная система управления продажами, которая:
- **Планирует** рабочее время (календарь активностей)
- **Измеряет** результаты (KPI метрики)
- **Вознаграждает** за достижения (система бонусов)

### Ключевые метрики:
- Summary Score (итоговый балл)
- Call Rate (частота визитов)
- Route Coverage (покрытие территорий)
- POSM & SKU Compliance (соответствие стандартам)
- Incentive Rate (ставка премирования)

## 🎨 Рекомендуемые дашборды

1. **Executive Dashboard** - для руководства
   - Общая производительность
   - Региональные сравнения
   - Прогноз бонусов

2. **Operational Dashboard** - для операционного управления
   - Тренды метрик
   - Качество исполнения
   - Использование времени

3. **Manager Dashboard** - для руководителей подразделений
   - Управление командой
   - Индивидуальная производительность
   - Workflow согласований

4. **Planning Dashboard** - для планирования
   - Календарь команды
   - Capacity planning
   - Оптимизация маршрутов

5. **Analytical Dashboard** - для глубинной аналитики
   - Корреляции метрик
   - Прогнозы
   - What-if сценарии
