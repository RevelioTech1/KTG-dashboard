# CA vs EVA: чего хватает, чего нет

Разбор по факту загруженных файлов `CA_Sep_26` и `EVA_Final_08`.

## Кто такой IBM

руководители направлений (IBM). Под каждым — его территории (точки) и
должности: TSM / JTSM / KPP Activator (исполнители) и BDM / RKAM (свёртки

## 1. Если есть только CA_Sep_26 — что пропадает с дашборда

### Останется (есть в CA)

- Список территорий и должностей (TSM / BDM / JTSM)
- Регион территории (где заполнен)
- Код BDM-руководителя (столбец A календаря)
- План-календарь активностей на сентябрь: отпуска, больничные, ЦИ, дорога,
  получение POSM, согласования с BUM
- Оценка потерь полевого времени и загрузки

### Пропадёт полностью (есть только в EVA)

| Блок дашборда | Почему нельзя |
| --- | --- |
| Средний балл KPI, медиана, распределение по баллам | В CA нет `summary_score` / `final_kpi_score` |
| Доля выполнивших норму (≥ 100) и без премии (< 80) | Нет баллов |
| Ставка премии, штрафы по турам, «зона быстрого выигрыша» | Нет `incentive_rate`, `tour_penalty` |
| Выполнение Call rate / Coverage / POSM / SKU / H/S | Нет план/факт по метрикам |
| Качество выкладки (ошибки в точках) | Нет `covered_pos` / `pos_with_mistakes` |
| Лидеры и аутсайдеры по KPI | Нечего ранжировать |
| Фильтр и аналитика по **IBM (фамилиям менеджеров)** | В CA нет имён IBM — только коды BDM |
| Рейтинги TSM / BDM / RKAM | Лист Rating 08 только в EVA |
| Схема KPI (`30% TOP-10 +70% KPP` и т.п.) | Только в EVA |

Итого: из текущего executive dashboard без EVA остаётся по сути **один блок —
потери полевого времени**, плюс оргструктура «территория → BDM → регион».

## Можно ли из CA собрать EVA Final?

**Нет.** CA — это план-календарь отвлечений от поля. EVA — это факт исполнения
KPI и расчёт премий. Пересекаются только справочные измерения.

| Что нужно для строки EVA | Есть в CA? |
| --- | --- |
| Код территории, должность, регион | Частично да |
| Привязка к BDM (код …00) | Да (столбец A) |
| Фамилия IBM | **Нет** |
| Type KPI / KPI Group | **Нет** |
| TOP-10, KPP, Mandatory, Call rate, Coverage | **Нет** |
| POSM, SKU, Distr/HS, ошибки в POS | **Нет** |
| Summary Score, Incentive, Tour Penalty | **Нет** |

Из CA можно восстановить только **скелет оргструктуры** (территория, регион,
должность, код BDM) и **календарь**. Собрать EVA Final из одного CA нельзя:
не хватает всех метрик результата и всей модели премирования.

Дополнительно периоды разные: EVA = август 2026, CA = сентябрь 2026, состав
территорий между месяцами не совпадает (10 только в CA, часть только в EVA).

## Что даёт связка обоих файлов

- EVA даёт KPI и фамилии IBM → аналитика по менеджерам и их точкам
- CA даёт загрузку на следующий месяц → потери времени по тем же кодам территорий
- Связь IBM ↔ территория строится из EVA; в CA имя IBM появляется только если
  код территории/BDM уже сопоставлен через EVA

Без периодической выгрузки EVA дашборд эффективности торговой команды
невозможён; CA его не заменяет.
